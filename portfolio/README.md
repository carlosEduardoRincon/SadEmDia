# Carlos Eduardo Rincon — Portfólio

Portfólio profissional com design futurista e minimalista, apresentando trajetória profissional e projetos do GitHub.

## Stack

- **React 19** + **TypeScript**
- **Vite** — build tool
- **Framer Motion** — animações fluidas e scroll-triggered

## Recursos

- 🎨 Tema escuro com acentos em cyan (#00d4ff)
- ✨ Animações de entrada com Framer Motion
- 🪟 Glassmorphism nos cards
- 📱 Layout responsivo com menu hamburger mobile
- 🔗 Links para [LinkedIn](https://www.linkedin.com/in/carloseduardorincon/) e [GitHub](https://github.com/carlosEduardoRincon)

## Como rodar

```bash
npm install
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173) no navegador.

## Build para produção

```bash
npm run build
npm run preview
```

## Estrutura

- `src/data.ts` — dados do perfil, experiência, projetos e certificações
- `src/components/` — componentes React (Hero, About, Experience, Projects, Skills, Contact)
